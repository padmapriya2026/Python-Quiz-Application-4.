# Python Quiz Application

## Project Description
The Python Quiz Application is a beginner-friendly General Knowledge quiz. It displays multiple-choice questions, accepts user answers, checks the answers, calculates the score, and displays the final result.

## Features
- Contains 5 multiple-choice questions
- Displays one question at a time
- Accepts user answers and provides feedback
- Calculates the final score
- Displays a performance message
- Allows the user to replay the quiz

## Technologies Used
- Python
- Google Colab

## Python Concepts Used
- Lists and dictionaries
- For loops and while loops
- Conditional statements
- User input and output
- Score calculation

## Scoring Rules
- Each correct answer earns 1 point.
- Incorrect answers earn 0 points.
- The maximum score is 5.

## How to Run
1. Open the notebook in Google Colab.
2. Run the cell containing the questions list.
3. Run the quiz application code.
4. Enter an option from 1 to 4 for each question.
5. View your final score and choose whether to play again.
